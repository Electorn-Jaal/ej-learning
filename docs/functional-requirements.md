# Шаардлагын жагсаалт (Functional / Non-functional)

Шинэчилсэн: 2026-09-21.

Шаардлага бүр **дугаартай**. Дугаарыг user story, тест, хөгжүүлэлтийн ажилд ишлэнэ.

## Төлөвийн тэмдэг

| Тэмдэг | Утга |
|---|---|
| ✅ | Хэрэгжсэн, **автомат тестээр** баталгаажсан |
| 🟡 | Хэрэгжсэн, автомат тестгүй — гараар шалгасан эсвэл шалгаагүй |
| ⬜ | Хэрэгжээгүй |
| ❓ | Клиентээр батлуулах шаардлагатай — одоогийн зан үйл нь шийдвэр биш, таамаг |

> Кодод байгаа нь хэрэгцээ батлагдсан гэсэн үг **биш**. Эсрэгээр, тест байгаа нь тухайн зан үйл
> санамсаргүй өөрчлөгдөхгүй гэсэн баталгаа мөн.

## Хамгийн түрүүнд шийдэх ❓-үүд

2026-09-21-ний шийдвэрээр дээрх долоогийн зургаа нь хаагдсан
([client-questions.md](client-questions.md) §11). Одоо хориглож байгаа нь:

1. **FR-D13** — англи хэлэнд ангийн хичээл байх ёстой гэж тогтсон, харин импортолсон өгөгдөлд
   байхгүй. Импортыг засах уу, эсвэл хуваарийг гараар үүсгэх үү.
2. **FR-E9** — нэг ангид нэг ангийн багш мөн үү (хариулт аваагүй).
3. **FR-D14** — амралт, баярын хуанли (дараа авахаар тохирсон).
4. **FR-C5 хэмжээ** — «нэг удаа» гэдгийг **өдөрт нэг удаа** гэж хэрэгжүүлсэн. Хичээл дахин
   оногдвол (нөхөх сургалт) өөр өдөр дахин өгнө. Хэрэв «хичээлд насан туршдаа нэг удаа» байх
   ёстой бол өөрчилнө.
