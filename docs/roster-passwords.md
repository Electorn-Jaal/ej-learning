# Сурагч, багшийн нууц үг сэргээх

2026-09-25-нд сургуулийн 277 бүртгэлийн нууц үгийг бүхэлд нь солив. Энэ баримт
яагаад тэгснийг, хэрхэн ажилладгийг, дахин хийх шаардлагатай болвол юу хийхийг
бичнэ.

## Яагаад

Бүртгэлүүд эхэндээ данс дугаараасаа гарсан нууц үгтэй байсан: `ej26s0106`
хэрэглэгчийн нууц үг `Ej26S0106!`. Хэн ч хүрэхгүй нэг компьютер дээр энэ
асуудалгүй. Сургууль интернэтэд гарсны дараа биш.

Хэв нь нэг л удаа тайлагдана. Нэг хүүхдийн нэвтрэх мэдээллийг харсан хүн
үлдсэн 276-гийн бүгдийг нь гаргана, тэдгээрийн нэр, анги, түвшин, өгсөн хариулт
бүрийн хамт. Нэг данс алдагдах нь бүх данс алдагдахтай тэнцэх бол тэр нь нууц
үг биш, зөвхөн нууц үгийн дүр.

Дээр нь `scripts/set-prototype-student-passwords.ts` гэдэг скрипт байсан ба тэр
нь нууц үгүүдийг яг тэр таамаглагдах хэв рүү **буцааж** тавьдаг. Тэр скрипт
туршилтын зориулалттай; production өгөгдлийн сан дээр ажиллуулж болохгүй.

## Юу хийдэг вэ

`artifacts/api-server/scripts/reset-roster-passwords.ts`.

- **Хамрах хүрээ:** `data_origin = 'REAL'` бөгөөд идэвхтэй сурагч, багш.
  **Админ орохгүй** — тэдгээр нь нэр бүхий хүмүүсийн өөрсдөө сонгосон нууц
  үгтэй бүртгэл ба скриптээр солих нь тухайн долоо хоногт сургуулийг барьж
  байгаа хүнийг гаргачих болно.
- **Нэвтрэх нэр хөндөгдөхгүй.** Нэр бол нууц зүйл биш, солих нь сургуулийн
  хэвлэчихсэн жагсаалт бүрийг хүчингүй болгоно, бас дугаарлалт нь бүртгэлээс
  хүүхэд олох арга.
- **Нууц үгийн хэлбэр:** `xa65-22xt-52ye` — дөрвөн тэмдэгтийн гурван бүлэг,
  зурааснаас тусгаарлагдсан. Цагаан толгойд **нүдээр андуурагддаг тэмдэгт
  байхгүй**: `O`, `0`, `l`, `I`, `1` аль нь ч алга. Хүүхэд цаасан дээрээс уншиж
  бичдэг тул энэ нь чимэг биш. Зураас нь код чангаар уншихад мөрөө алдахаас
  сэргийлнэ. 59 бит энтропи.
- **Бичилт нь нэг transaction.** Дунд нь тасарвал нэг ч бүртгэл солигдохгүй —
  хагас нь солигдсон сургууль бол хамгийн муу төлөв, учир нь хэн нь солигдсоныг
  хэн ч мэдэхгүй. `pg_advisory_xact_lock` нь хоёр хүн зэрэг ажиллуулахаас
  хамгаална.
- **Шалгалт.** Бичсэний дараа скрипт эхний сурагч, эхний багшийн шинэ нууц
  үгээр **бодитоор нэвтэрч үзнэ**. Чимээгүйхэн өөр зүйл hash хийсэн reset-ийг
  эс бөгөөс эхний өглөө нэвтэрч чадаагүй хүүхэд олж мэднэ.
- **Юу ч хэвлэхгүй.** Нууц үгүүд зөвхөн хоёр файлд очно.

## Ажиллуулах

Анхдагчаар **туршилт**: тоог хэлж, жишээ нууц үг үзүүлээд зогсоно.

```
pnpm --filter @workspace/api-server reset-roster-passwords
```

Хэрэгжүүлэх:

```
pnpm --filter @workspace/api-server reset-roster-passwords -- --apply --yes
```

`--yes` байхгүй бол `--apply` татгалзана.

### Аль өгөгдлийн сан руу очихыг шалгах

Скрипт `DATABASE_URL`-ийг дагана, түүнийг `.env`-ээс уншина. `.env` дотор
локал сан заасан байдаг:

```
DATABASE_URL="postgresql://.../ej_learning_local"
```

Серверийг засахын тулд SSH tunnel нээгээд `DATABASE_URL`-ээ **дарж бичих**
хэрэгтэй:

```
ssh -L 55432:localhost:5432 <server>        # өөр цонхонд нээлттэй үлдээ

DATABASE_URL='postgresql://<хэрэглэгч>:<нууц үг>@localhost:55432/<сан>' \
  pnpm --filter @workspace/api-server reset-roster-passwords

DATABASE_URL='postgresql://...' \
  pnpm --filter @workspace/api-server reset-roster-passwords -- --apply --yes
```

Ажиллуулахаасаа өмнө эхний мөрийн гаралтыг **уншина уу**: «Сурагч N, багш M».
Хэрэв тоо нь хүлээж байснаас өөр бол буруу сан руу холбогдсон байна.

### Хийснийг батлах

Reset хийсний дараа хуучин хэвийн нууц үг **ажиллахаа болих ёстой**. Сервер
дээрх нэг дансаар `Ej26S0106!` маягийн нууц үгээр нэвтэрч үзээд татгалзвал
болсон. Нэвтэрвэл reset тэр сан руу хүрээгүй гэсэн үг.

## Файлууд

Хоёр CSV `local-data/generated/` дотор `0600` эрхтэй үүснэ:

```
student-passwords-YYYY-MM-DD.csv    Анги, Нэр, Нэвтрэх нэр, Нууц үг
staff-passwords-YYYY-MM-DD.csv      Багшийн код, Нэр, Нэвтрэх нэр, Нууц үг
```

**Эдгээр нь цорын ганц хувь.** Өгөгдлийн сан нь зөвхөн hash хадгална, тэрхүү
hash-аас нууц үгийг сэргээх арга байхгүй. Файлаа алдвал сэргээхгүй — дахин
reset хийхээс өөр зам байхгүй, тэгвэл бүх хүүхэд шинэ нууц үгтэй болно.

`local-data/` бүхэлдээ `.gitignore`-д орсон тул эдгээр файл git рүү орохгүй.

### Анхаарах

Гаралтыг файл руу чиглүүлэх (`| Tee-Object`, `> out.txt` гэх мэт) нь нууц үг
хадгалахгүй — скрипт тэднийг хэвлэдэггүй, зөвхөн бүртгэлийн мөрүүд бичигдэнэ.
Гэхдээ ийм файл репогийн үндэст үлдэх нь төөрөгдүүлнэ. `roster-passwords.txt`
гэх мэт файл үүсгэсэн бол устгах, эсвэл `.gitignore`-д нэмэх хэрэгтэй — `git
add -A` түүнийг commit хийж мэднэ.

## Дараа нь

Хэвлээд гардуулсны дараа CSV-г хадгалах эсэхийг сургууль шийднэ. Хэрэв
устгавал алдсан нууц үгийг сэргээх ганц арга нь дахин reset.

Хүүхэд, багш өөрсдөө нууц үгээ солих боломжтой (`/password`), энэ нь тэднийг
энэ жагсаалтаас гаргана — хэн нэгэн солисон бол CSV дээрх мөр нь хуучирна.
