# Прототипэд хэрэгтэй өгөгдөл

> 3 хичээлээр ажиллах прототип гаргахад юуг цуглуулах вэ.
> Сүүлд шинэчилсэн: 2026-09-17

Энэ баримт нь **юу цуглуулахыг** тодорхойлно. Хэрхэн оруулахыг биш — тэрийг
систем хийнэ. Цуглуулж буй хүн энэ файлыг уншаад хангалттай байх ёстой.

---

## 1. Юуг үзүүлэх гэж байна вэ

Гурван хичээлээр дараах гогцоо бүтэн эргэх ёстой:

```
Сурагч нэвтэрнэ
  → өнөөдрийн хичээлээ хардаг (номын тодорхой хуудас)
  → дэвтэр дээрээ ажиллана
  → веб дээр шалгах асуултад хариулна
  → багш үр дүнг хардаг
  → дутуу байвал систем өөрөө суурь хичээл рүү буцаана
```

Энэ гогцоо **аль хэдийн ажиллаж байна** — гэхдээ зөвхөн 10-р ангийн алгебрын
нэг бүлэг дээр. Гурав болгоход дутуу байгаа зүйл бол **код биш, агуулга**.

---

## 2. Одоо юу байгаа вэ

| Хичээл | Байгаа зүйл | Дутуу зүйл |
|---|---|---|
| **Математик** | 10-р анги, 1 бүлэг, 6 чадвар, 6 хичээл, 18 асуулт, ном PDF | Бусад бүлэг, бусад анги |
| **Англи хэл** | CEFR A1–C2, 36 чадвар, 36 хичээл, 60 асуулт, 82 сурагч | **Ном байхгүй** |
| **Монгол хэл** | Хичээл бүртгэгдсэн, өөр юу ч алга | **Бүгд** |

Өөрөөр хэлбэл: математик бүтэн, англид ном дутуу, монгол хэл хоосон.

---

## 3. Өгөгдлийн гинж

Дараалал чухал. Доод шатгүйгээр дээд шат утгагүй болно.

```
Ном (PDF)
  └── Бүлэг / хэсэг  ── хуудасны дугаартай
        └── Сэдэв
              └── Чадвар  ←──────────┐
                    ├── Өдрийн хичээл │ урьдач нөхцөл
                    └── Асуултууд     │
                                   ───┘
```

Тусдаа, зэрэгцээ:

```
Анги ── Сурагч (элсэлт)
  └── Багш (анги × хичээл)
```

**Чухал ялгаа:** *сэдэв* нь номын бүтэц (юуны тухай), *чадвар* нь сурагч юу
хийж чаддаг болох (хэмжиж болох зүйл). Номын хуудас сэдэв дээр өлгөгддөг,
хичээл болон асуулт чадвар дээр өлгөгддөг. Нэг сэдэвт хэд хэдэн чадвар байж
болно.

## 4. Блок бүрээр

### 4.1 Анги

| Багана | Заавал | Тайлбар | Жишээ |
|---|:---:|---|---|
| `class_code` | ✔ | Давхардахгүй код | `MGL-G09-A` |
| `name_mn` | ✔ | Багшийн хэлдэг нэр | `9А` |
| `grade_number` | ✔ | 1–11 | `9` |
| `school_year` | ✔ | Хичээлийн жил | `2026-2027` |

#### ⚠ Нэг анги — гурван өөр бичлэг

`10-1`, `10-A`, `10А` гэсэн гурван бичлэг нь **нэг ижил ангийг** заана.
Дэлгэрэнгүй:

| Бичлэг | Утга |
|---|---|
| `10-1` | Дараалсан дугаар: 1 дэх анги = **А** |
| `10-2` | 2 дахь анги = **Б** |
| `10-3` | 3 дахь анги = **В** |
| `10-A` | **Латин A** (U+0041) — кирилл бичих боломжгүй үед |
| `10А` | **Кирилл А** (U+0410) — жинхэнэ бичлэг |

Хүн нүдээрээ ялгаж чадахгүй. Компьютерийн хувьд `10-A` (латин) ба `10А`
(кирилл) нь **огт өөр** тэмдэгт.

**Аль хэдийн болсон:** CEFR импорт үүнийг мэдээгүй тул нэг ангийг хэд хэдэн
анги болгож хуваасан — 7-р анги `7-1` (4 сурагч) ба `7-A` (10 сурагч) гэж
хоёр тусдаа анги болсон. Нэг ангийн хүүхдүүд тусдаа жагсаалтад тархсан.

**Хөрвүүлэх дүрэм:**

```
<анги>-<n>  →  <анги> + [А, Б, В, Г, Д][n-1]
<анги>-A    →  <анги>А   (латин → кирилл)
```

⚠ **Латин `B` тодорхойгүй.** Дараалалаар бол **Б** (2 дахь), хэлбэрээр бол
**В**. Файл өгөхдөө аль болохыг **заавал хэлээрэй**.

> **Хамгийн зөв шийдэл:** файл өгөхдөө анги бүрийг **кириллээр, нэг л
> хэлбэрээр** бич — `10А`, `10Б`. Тэгвэл хөрвүүлэх шаардлагагүй.

хэвлэгдсэн хуудасны дугаар, PDF файлын хуудасны дугаар хоёр **ижил биш**.

> Тогтоох арга: PDF-ээ нээгээд, дээр нь **«25» гэж хэвлэгдсэн** хуудсыг ол.
> PDF-ийн хэддүгээр хуудас байна? Хэрэв 37 бол `page_offset = 12`.

ганцхан ангийн агуулга байгаа.

## 5. Хэр их хангалттай вэ

Прототип бол **олон биш, бүтэн** байх ёстой. Нэг хичээлээр:

| Юу | Тоо |
|---|---|
| Анги | **1** |
| Сурагч | **10** |
| Багш | **1** |
| Ном | **1** |
| Бүлэг | **1** (6–10 хэсэгтэй) |
| Чадвар | хэсэг бүрд **1** |
| Өдрийн хичээл | чадвар бүрд **1** |
| Асуулт | чадвар бүрд **3–5** |
| Урьдач нөхцөл | бүлэг дотроо **5–8** |

Нийт 3 хичээлээр: **30 сурагч, 3 багш, 3 ном, ~20 чадвар, ~70 асуулт.**

**Анги хооронд буухыг үзүүлэхийг хүсвэл** нэг хичээл дээр нэмж доод ангийн
2–3 чадвар, тэдгээрийн хичээл, асуулт хэрэгтэй. Бүтэн ном биш — хамгийн
холбоотой 2–3 сэдэв хангалттай.

## 7. Өмнө нь бэрхшээл болсон зүйлс

Эдгээр нь таамаг биш, аль хэдийн тохиолдсон:

1. **Excel анги-ийн кодыг огноо болгосон.** `8-1` → `2026-08-01`, бүх
   дериватив хуудсанд. Зөвхөн эх хуудаснаас уншиж сэргээсэн.
   → **Анги-ийн кодыг текст форматаар өг**, эсвэл `8-1` биш `G08-1` гэж бич.

2. **Зөв хариулт байхгүй байсан.** Дээрх 4.8-г үзнэ үү.

3. **Ном 128 MB байсан.** Вэб дээр нээхэд тэвчихийн аргагүй. 3.56 MB болгож
   шахсан. → PDF-ээ өгөхөд хэмжээг нь хэл, бид шахна.

4. **Хэвлэгдсэн хуудас ≠ файлын хуудас.** Дээрх 4.4-г үзнэ үү.

5. **Нэг багш = нэг хичээл гэж үзсэн.** Багш 9А-д монгол хэл, 10А-д математик
   заадаг байсан тул хяналтын самбар бүх зүйлийг буруу нэгтгэсэн.
   → Багш × анги × хичээл, мөр бүрд нэг хослол.

## 8. Excel файлуудаас юуг хайх вэ

Сургуулиас ирсэн Excel-үүдийг нэг бүрчлэн уншихын оронд **шигших** хэрэгтэй.
Файл бүрд нэг л асуулт: *энэ хуудас дээрх 9 блокийн алийг нь тэжээж чадах вэ?*

### 8.1 Эхлээд хуудас бүрийн толгой мөрийг харна

Ажлын дэвтэрт олон хуудас байдаг. Аль нь **эх сурвалж**, аль нь **томьёогоор
гаргасан** болохыг ялгах нь хамгийн чухал — доорх 8.4-г үзнэ үү.

```bash
python scripts/src/dump-headers.py <файл.xlsx>
```

Энэ нь хуудас бүрийн нэр, багануудын толгой, мөрийн тоог хэвлэнэ. Дараа нь
доорх хүснэгтээр тааруулна.

### 8.2 Таних шалгуур

Багананы толгойд дараах **үгс** байвал тухайн блокийн өгөгдөл байх магадлалтай.
Монгол, англи аль нь ч байж болно.

| Блок | Толгойд хайх үг | Заавал байх нөхцөл |
|---|---|---|
| **Анги** (4.1) | анги, бүлэг, class, grade | Мөр бүр нэг анги |
| **Сурагч** (4.2) | нэр, овог, суралцагч, код, student, register | **Мөр бүр нэг сурагч**, тогтвортой кодтой |
| **Багш** (4.3) | багш, teacher, заадаг, хичээл | Багш × анги × хичээл хослол |
| **Номын бүтэц** (4.5) | бүлэг, хэсэг, гарчиг, хуудас, page, unit, chapter, section | **Хуудасны дугаартай** байх |
| **Сэдэв/чадвар** (4.6) | сэдэв, чадвар, skill, суралцахуйн үр дүн, outcome, topic | Тогтвортой кодтой бол хамгийн сайн |
| **Өдрийн хичээл** (4.7) | хичээл, төлөвлөгөө, долоо хоног, plan, lesson, week | Аль чадварынх нь мэдэгдэх ёстой |
| **Асуулт** (4.8) | асуулт, сорил, тест, item, question, сонголт, option | **Зөв хариулт хамт байх** |
| **Дүн** (шалгалтын үр дүн) | оноо, дүн, үнэлгээ, score, mark, result, хувь | Мөр бүр нэг сурагч |
| **Урьдач нөхцөл** (4.9) | урьдач, шаардлага, суурь, prerequisite, depends | Хоёр чадварыг холбосон байх |

### 8.3 Нэг дэвтэрт хэд хэдэн төрлийн өгөгдөл байдаг

Бидэнд ирсэн ганц бодит Excel дээр **нэг файлд гурван огт өөр** төрлийн
өгөгдөл байсан. Энэ нь онцгой тохиолдол биш — ийм байх нь энгийн зүйл.
Тиймээс *файл* биш, **хуудас бүрийг тусад нь** шигшинэ:

| Хуудасны хэлбэр | Ийм багана байвал | Юуг тэжээх вэ |
|---|---|---|
| **Онлайн формын хариулт** | `Timestamp`, `Score`, сурагчийн код, асуулт бүр нэг багана | Сурагч, анги, асуултын банк, оноо |
| **Агуулгын зураглал** | чадвар, ном, хэсэг, **хуудас** | Чадвар, номын бүтэц, хуудасны муж |
| **Сурагчийн төлөвлөгөө** | сурагчийн код, долоо хоног, чадвар, даалгавар | Хэнд юу оноогдсон |

**Хамгийн үнэтэй анзаарга:** тэр файлд асуултын толгой мөр нь
`[код][түвшин][чиглэл] асуултын бичвэр` гэсэн **бүтэцтэй** байсан. Тиймээс 60
асуултын банкийг бүтнээр нь, кодтой нь, ангилалтай нь гаргаж авсан.

> Толгой мөрөнд ийм давтагдах бүтэц байвал заавал хэлээрэй. Гар ажил
> хэдэн өдрөөр багасна.

### 8.4 Аль хуудас эх сурвалж вэ

⚠ **Энэ хамгийн чухал асуулт.** CEFR файлд `Grade / Class` баганыг зөвхөн
`Form Responses 1`-ээс уншсан. Бусад хуудсууд түүнээс томьёогоор гаргасан
байсан ба Sheets `8-1`-ийг **огноо гэж уншаад** `2026-08-01` болгож
хувиргасан. Дериватив хуудас бүрд анги устсан байсан.

Тиймээс файл өгөхдөө хэлээрэй:

- Аль хуудас нь **гараар бичигдсэн** вэ
- Аль нь **томьёогоор** гарсан вэ

Эргэлзвэл: нүдэн дээр дарж томьёо (`=`) харагдаж байна уу гэдгийг шалга.

### 8.5 Файл өгөхийн өмнө — хийх ба хийхгүй

**Хийхгүй:**

- ❌ **Цэвэрлэхгүй.** Буруу харагдсан ч тэр чигээр нь өг. Бид цэвэрлэнэ
- ❌ **Анги, кодыг дахин бичихгүй.** Дахин бичих бүрд алдаа орно
- ❌ **Хуудас устгахгүй.** Хэрэггүй мэт санагдсан хуудас хэрэгтэй байж мэднэ
- ❌ **Нэгтгэхгүй.** Мөр бүр нэг сурагч байх ёстой, нийлбэр тоо хэрэггүй

**Хийх:**

- ✔ Файлыг **байгаа чигээр нь** өг
- ✔ Аль хуудас гараар бичигдсэнийг хэл
- ✔ Зөв хариултын түлхүүр тусдаа байвал **хамт** өг
- ✔ Ном PDF байвал хамт өг, хэмжээг нь хэл

### 8.6 Аль файл хэрэггүй вэ

Дараах тохиолдолд тэр файл ажиллахгүй — цаг үрэхгүйн тулд:

| Шинж | Яагаад ажиллахгүй вэ |
|---|---|
| Зөвхөн нийлбэр, дундаж тоо | Сурагч тус бүрийн мөр байхгүй бол хэн юуг мэдэхгүйг тогтоох аргагүй |
| Нэр байгаа, код байхгүй | Ижил нэртэй хоёр сурагчийг ялгах боломжгүй |
| Хуудасны дугаар байгаа, ном нь тодорхойгүй | Аль номын 24-р хуудас гэдэг нь мэдэгдэхгүй |
| Асуулт байгаа, зөв хариулт байхгүй | Оноо тавих боломжгүй (нэг удаа сэргээсэн, дахихгүй) |
| Скан хийсэн зураг, PDF доторх хүснэгт | Excel биш. Гараар бичих шаардлагатай болно |

### 8.7 Файл тус бүрд бөглөх маягт

```
Зөв хариулт     : бий / үгүй / хамаарахгүй

```
