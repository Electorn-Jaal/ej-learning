гэж үзээд Figma-г засна. Шинэ token эсвэл component хэрэгтэй болбол эхлээд
кодод нэмээд, дараа нь Figma-д тусгана.

## Figma файлын бүтэц

Хуудсууд одоогийн цэсний бүлгүүдийг (`Shell.tsx`) дагана. Шинээр зохиосон
ангилал ашиглахгүй.

```text
EJ Learning
├── 01 Foundations    index.css-ийн token-ууд: өнгө (light/dark), фонт, radius
├── 02 Components     components/ui/-д байгаа, бодитоор ашиглагддаг component-ууд
├── 03 UX Flows       Student · Teacher · Admin · Guardian
├── 04 Web            role бүрт нэг хуудас: Student · Teacher · Admin · Guardian · Manager
├── 05 Mobile         одоогийн 390px харагдац; тусдаа app төлөвлөгдсөн үед нэмнэ
└── 99 Archive        хуучин хувилбаруудыг устгахгүй, энд зөөнө
```

> **Одоогийн файлд:** Starter тариф 3 хуудас зөвшөөрдөг тул дээрх бүтцийг
> `01 Design System` (01–02), `02 Screens` (03–05), `99 Archive` гэсэн гурван
> хуудсанд Section-оор хуваасан. Professional тариф руу шилжвэл дээрх бүтэц
> рүү задална. Явц: [progress.md](progress.md).

04 Web доторх role бүрийн хуудас гурван section-тэй:

1. **Одоо байгаа**: кодоос яг байгаагаар нь авсан дэлгэц ([pages.md](pages.md)).
   Хэн нэгэн кодыг өөрчилбөл энд шинэчилнэ.
2. **Төлөвлөсөн**: шаардлагад байгаа, кодод дутуу эсвэл байхгүй дэлгэц
   ([planned.md](planned.md)). Frame бүрийн нэрэнд UC дугаар ба төлөвийг
   бичнэ, жишээ нь `UC04 · Хэсэгчлэн · Сэдэв солих preview`.
3. **Шинэ санаа**: одоогийн дэлгэцийн дахин боловсруулсан хувилбар. Батлагдвал
   кодод орж, "Одоо байгаа" хэсэгт шилжинэ. Хуучин хувилбар Archive руу орно.

Manager хуудас D05 шийдэгдэх хүртэл зөвхөн "Төлөвлөсөн" хэсэгтэй байна.

## Одоогийн web-ийг Figma-д оруулах

Дэлгэц бүрийг 1440px ба 390px өргөнөөр, role бүрийн бүртгэлээр нэвтэрч
авна. Мөн төлөв бүрийг авна: өгөгдөлтэй, хоосон, ачаалж байгаа, алдаатай.
Зураг биш, засаж болох layer хэрэгтэй бол html.to.design зэрэг HTML-ээс
Figma руу хөрвүүлэх plugin ашиглана. Хөрвүүлсэн layer-уудыг 02 Components-ийн
component-оор солих нь дараагийн алхам.

## Role

Кодод дөрвөн role бий. Admin тусдаа app биш: багшийн shell дотор "Удирдлага"
гэсэн бүлэг нэмэгдэж харагдана.

- **Student**: `/`
- **Teacher**: `/teacher`
- **Admin**: `/teacher` + Удирдлага бүлэг
- **Guardian**: `/`, хүүхдийнхээ нэг хуудас
